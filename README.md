# Titanic - Data Analysis
 
This project aims to clean and analyze Titanic passenger data in order to create a predictive algorithm that estimates a passenger's probability of survival. The process consists of the following steps:
 
1. Data import and initial cleaning
2. Exploratory data analysis
3. Quantitative data analysis
4. Development of the predictive algorithm
5. Evaluation of the model's effectiveness
6. Export of the data to an Excel spreadsheet
